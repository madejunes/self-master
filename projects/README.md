# Projects

Projects are a central part of this program.

## Project Principles

A good project should preferably:

- solve or investigate a realistic problem;
- be connected to current engineering practice or a current technology issue;
- require meaningful engineering decisions;
- have observable outcomes;
- expose trade-offs;
- allow reflection and critique;
- increase in ambiguity and independence over time.

Projects should not merely be tutorial implementations.

## Selection

Project selection will be discussed with the learner before each major project.
