# Program Decisions

## 2026-08-30 — Program Direction

### Decision

Create a self-directed master's-level program centered on Software
Engineering, with Quality Engineering and AI Engineering as major areas.

### Rationale

These areas align with the learner's stated goal of becoming highly capable
and provide a coherent progression from traditional software engineering
through software quality into intelligent software systems.

### Evidence / Reference

The structure is consistent with established graduate software-engineering
curriculum guidance, particularly ACM/IEEE-CS GSwE2009 and Carnegie Mellon
Software Engineering Institute materials.

## 2026-08-30 — Project-Driven Learning

### Decision

Use realistic projects as a major mechanism for learning.

### Rationale

The learner prefers learning by doing and wants projects connected to
real-world and current problems.

## 2026-08-30 — Academic Evidence

### Decision

Use substantial real academic and authoritative material.

### Requirements

- Do not hallucinate references.
- Verify citations.
- Prefer primary/peer-reviewed/official sources where appropriate.
- Use books and high-quality educational material for foundations.
- Use current literature for rapidly changing areas such as AI.

## 2026-08-30 — Persistent Memory

### Decision

GitHub repository is the source of truth; conversations are working sessions.

### Rationale

The program may span a long period and conversations may become fragmented.
A version-controlled record provides continuity and preserves decisions,
progress, and evidence.

## 2026-08-30 — Current Mode

### Decision

Remain in PLAN mode until the learner explicitly chooses to begin.
